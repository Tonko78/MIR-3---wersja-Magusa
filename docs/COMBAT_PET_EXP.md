# EXP i statystyki petów bojowych

EXP kumulacyjnie liczone od L0; przejście L0 → L1 wymaga 1000 EXP. Podstawa oznacza statystyki przed modyfikatorem poziomu walki (z uwzględnieniem poziomu przywołania).

| --- | --- | --- | --- |
| L1 | 2000 | 1000 | 75% |
| L2 | 3000 | 3000 | 80% |
| L3 | 4000 | 6000 | 85% |
| L4 | 5000 | 10000 | 90% |
| L5 | 6000 | 15000 | 95% |
| L6 | 7000 | 21000 | 100% |
| L7 | 8000 | 28000 | 105% |
| L8 | 9000 | 36000 | 110% |
| L9 | 10000 | 45000 | 115% |
| L10 | 11000 | 55000 | 120% |
| L11 | 12000 | 66000 | 125% |
| L12 | 13000 | 78000 | 130% |
| L13 | 14000 | 91000 | 135% |
| L14 | 15000 | 105000 | 140% |
| L15 | — (MAX) | 120000 | 145% |

Dodatni bonus zaczyna się od L7; L1–L5 mają karę, a L6 odpowiada podstawie (0% bonusu). Wzór bonusu: (poziom walki − 6) × 5%, z ograniczeniem wynikowych statystyk do minimum 0. Limit to L15 (+45%); po osiągnięciu limitu pet nie awansuje dalej.
